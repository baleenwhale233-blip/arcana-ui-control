# Source Decision

Before generating or editing, choose how the original screen enters the workflow.

## Options

- `codex_image_seed`: Codex/image2 generates the first UI image. Accept one result as the anchor.
- `uploaded_anchor`: the user provides an existing UI image. Use it as the anchor.
- `provider_seed`: OpenAI, generic_http, or command generates the first image.
- `manual_seed`: write a handoff package for a human-operated image tool.
